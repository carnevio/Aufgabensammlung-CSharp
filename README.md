# Aufgabensammlung CSharp

Dieses Repository enthaelt eine Sammlung von Aufgaben und Loesungen zur Programmiersprache C#. Die Aufgaben wurden im Rahmen der Ausbildung geloest und dienen zur Uebung der grundlegenden Programmiertechniken in C#.

## Inhalt

In diesem Repository werden verschiedene Aspekte der Programmierung mit C# behandelt, darunter:

- Einfache Ein- und Ausgabe
- Bedingungen (if/else, switch)
- Schleifen (for, while, do-while)
- Methoden
- Arrays und Listen
- Grundlegende objektorientierte Programmierung (OOP)

## Verwendete Technologien

- C#

## Voraussetzungen

- .NET SDK (mindestens .NET 6.0 empfohlen)
- Ein geeigneter C# Editor oder eine IDE (z.B. Visual Studio oder Visual Studio Code)

## Nutzung

1. Repository klonen:

```bash
git clone https://github.com/carnevio/Aufgabensammlung-CSharp.git
```

2. In das gewuenschte Aufgabenverzeichnis wechseln:

```bash
cd Aufgabensammlung-CSharp/Aufgabe_X
```

3. Projekt in Visual Studio oder einer anderen IDE oeffnen (Rider, usw.).

4. Build und Ausfuehrung starten.
